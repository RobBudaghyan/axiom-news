# Axiom News v2

A Telegram news digest bot for a small private group (~20 people). Every hour it
collects ~100 RSS news feeds, groups duplicate stories with one AI pass, and sends
each user a short digest at their chosen times. Runs on free tiers only
(GitHub Actions + Cloudflare Workers/D1 + Gemini).

Status: Step 1 (foundation, design, sources). Nothing is deployed yet.
See `PROJECT_NOTES.md` for status and `docs/ARCHITECTURE.md` for the design.
